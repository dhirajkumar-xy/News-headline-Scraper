# News Headline Web Scraper

## Description

This is a Python web scraping project that extracts news headlines from a public news website and saves them in a text file.

## Features

- Fetches a news webpage using the Requests library
- Parses HTML using Beautiful Soup 4
- Extracts headlines from h1, h2, and h3 tags
- Removes duplicate headlines
- Saves the extracted headlines in headlines.txt
- Uses error handling for request failures

## Technologies Used

- Python
- Requests
- Beautiful Soup 4
